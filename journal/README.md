# Daily Journal

One file per workday: `YYYY-MM-DD.md`. Three bullets per section is enough.

## Template

```markdown
## What I did today
- ...

## Blockers / risks
- ... (or "nothing")

## What I'll do tomorrow
- ...

## Decisions made today
- Link to `decisions/...` if any
```

## Why this matters

Keeps the timeline honest. Anyone reviewing the project later (future-you,
sanity-checker, investor) can see what happened day by day.
