# Decision Log

One file per significant decision. Filename: `YYYY-MM-DD_<short-slug>.md`.

Each entry contains:

1. **Decision** — what was decided, in one sentence
2. **Context** — what triggered the decision
3. **Alternatives considered** — at least two
4. **Rationale** — why we picked what we picked
5. **Reversible?** — yes/no, and if yes, what would reverse it

## Example skeleton

```markdown
## Decision
[One sentence]

## Context
[Paragraph]

## Alternatives considered
1. [Alternative A]
2. [Alternative B]

## Rationale
[Paragraph]

## Reversible?
[Yes/no + reasoning]
```

## Why this matters

If Phase 0 succeeds, the decision log + journal + commit history is the diligence
package an investor will ask for. If Phase 0 fails, the same artifacts show that
the experiment was executed honestly.
